# Aurum-Logos

Repositorio de logotipos de canales para el catálogo de **Aurum TV** y el ecosistema **Aurum Labz**.

Cada logotipo se encuentra organizado en una carpeta con el **nombre del canal** y contiene su archivo correspondiente `logo.png`.

---

## 📁 Estructura del Repositorio

```text
Aurum-Logos/
├── <Nombre del Canal>/
│   └── logo.png
├── .gitignore
└── README.md
```
